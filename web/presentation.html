Problem Statement & Solution

02 / EXECUTIVE SUMMARY

⚠️ The Network Monitoring Challenge

Modern Local Area Networks (LANs) consist of heterogeneous endpoints (IoT devices, servers, workstations, network switches, APs).

  • Traditional ICMP pings fail when firewalls block ping packets.
  • Standard SNMP configurations require tedious manual setup.
  • Existing tools suffer from delayed UI feedback and high resource overhead.

✨ The NetMonitor Solution

A zero-dependency, local-first NOC Operational Intelligence platform that combines multi-protocol probe telemetry with instant visualization.

  • Layered Multi-Protocol Engine: ARP + ICMP + TCP Probe fallback.
  • Auto-Topology Synthesis: Instant hierarchical node graph.
  • Live Event Streaming: Real-time 600ms telemetry updates.
  • Full Interactive CRUD: Add, Edit, Manage, and Delete devices.

Step-by-Step Discovery Workflow

04 / DISCOVERY ENGINE

🔄 Layered Discovery Execution Pipeline

1. Subnet Lookup

UDP route lookup auto-detects IPv4 subnet range.

2. Multi-Probe

Layer-2 ARP $\rightarrow$ Layer-3 ICMP $\rightarrow$ Layer-4 TCP 80/445 probes.

3. Classification

MAC OUI + Hostname semantics infer device category.

4. Live Streaming

Immediate event callbacks update UI on-the-fly.

5. SQLite Audit

Devices, scan totals, & alert events persisted to DB.

Security & Safety Audit

07 / SECURITY FRAMEWORK

🔒 Robust Defense Mechanisms

  • SQL Injection Immunity: 100% Parameterized queries using SQLite `?` bindings.
  • XSS Prevention: Safe DOM property assignments (`textContent`).
  • Local-First Data Privacy: Offline OUI resolution ensures zero external data leak.
  • Network Safety: Non-destructive, bounded threadpools prevent network overload.

🛡️ Privilege Management

  • Runs by default in **unprivileged fallback mode** using standard OS pings and ARP cache reads.
  • Elevated root access (`sudo`) is strictly optional for Layer-2 raw packet creation.
  • Socket binding falls back gracefully to `127.0.0.1`.
