01 / CAPABILITIES

Quietly thorough.
Built for the real LAN.

Watchtower layers practical network signals into one calm interface, so a blocked ping or unfamiliar MAC does not leave you guessing.

01

Discover devices

Detect the active IPv4 subnet and scan it in the background without freezing the interface.

⌁
02

Track change

Devices that disappear remain visible as Offline, making joins and leaves easy to follow.

◌
03

Identify hardware

Resolve vendor names locally from OUI data, with an optional lookup fallback when needed.

⌗
04

Export the record

Export IP, MAC, vendor, hostname, status, latency, and last-seen details to CSV.

02 / THE WORKFLOW

From signal
to certainty.

Each host is evaluated in layers. ARP when available, ICMP when possible, then bounded TCP checks when the network stays quiet.

01

Map the subnet

A UDP route lookup identifies the active interface and local network range.

02

Scan in the background

Worker threads keep the CustomTkinter UI responsive while results arrive safely through a queue.

03

Build a useful record

Reverse DNS, vendor data, latency, and status come together in one exportable table.
